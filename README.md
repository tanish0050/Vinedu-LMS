# Vinedu LMS

Vinedu is a learning management system for engineering students.

## Features

- Student registration and login
- Engineering courses, including DSA, Machine Learning and Artificial Intelligence
- Course lessons and reading material
- Five-question quizzes with score and attempt history
- Course progress tracking
- Student profile and profile photo
- Study planner and focus timer
- Notifications for new courses and meetings
- Admin panel to manage courses, students and meetings
- Light and dark themes
